Privacy Policy

Last updated: November 18, 2026

Scope

This policy covers personal software tools built and operated by Justin (Guanda) Chen for his own use, including a personal email assistant ("Hermes Mail") that reads and labels the owner's own Gmail messages.

What data the tools access

With the account owner's explicit OAuth consent, the email assistant reads message metadata and content from the owner's own Google account in order to summarize incoming mail, flag items that need a reply, and move promotional mail to Trash. No data is collected from anyone else's account.

How data is used

Accessed email data is used solely to produce summaries and actions for the account owner. It is not sold, rented, transferred, or disclosed to third parties, and it is not used for advertising, profiling, or training machine-learning models.

Storage and retention

OAuth credentials and a local record of processed message identifiers are stored on the owner's own computer. Message content is processed in memory and is not retained beyond the generated summary. Local records can be deleted at any time.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions). Revocation takes effect immediately.
